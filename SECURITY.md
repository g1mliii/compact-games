# Security policy

## Supported versions

Security fixes are provided for the latest released version of Compact Games.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/g1mliii/compact-games/security/advisories/new).
Do not open a public issue for a vulnerability that has not been disclosed and
fixed.

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation you have. Reports will be reviewed privately before a
coordinated fix and disclosure.
